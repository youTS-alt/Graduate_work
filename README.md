# Graduate_work // Веб-система управления взаимоотношениями с клиентами гостиницы на базе технологии ИИ-агентов

# Описание

  Разрабатываемая информационная система реализована как веб-приложение с разделением на клиентскую и серверную части, объединенные единым протоколом взаимодействия HTTP(S), применяемым для передачи документов и ресурсов веб-интерфейса. Клиентская часть представлена веб-интерфейсом, работающим в браузере и формируемым на основе серверных HTML-шаблонов, а также сопровождаемых запросов на загрузку ресурсов согласно современным веб-стандартам. Серверная часть построена с использованием фреймворка Django, который обеспечивает маршрутизацию запросов, формирование ответов, применение механизмов безопасности (включая CSRF-защиту), а также интеграцию с базой данных через ORM.

  Целью разработки является создание веб-ориентированной информационной системы, обеспечивающей автоматизацию основных процессов учета и сопровождения гостей, обработки обращений, управления бронированиями и задачами, а также предоставляющей пользователю единый интерфейс для работы с данными. Для достижения поставленной цели сформулированы следующие задачи: спроектировать архитектуру программного обеспечения, реализовать серверную часть на основе веб-фреймворка, организовать хранение данных в базе данных, разработать пользовательский интерфейс для просмотра и управления сущностями, обеспечить выполнение типовых информационных запросов (добавление, выборка, обновление, удаление) и интегрировать сервисные механизмы, повышающие качество сопровождения и контроля (например, ведение журнала аудита и автоматическая фиксация состояния интерфейса).

# Установка
1. Запустите `VS Code`.
2. Выберите `File -> Open Folder`.
3. Откройте папку проекта `HotelMate_AI_CRM`.
4. Откройте встроенный терминал: `Terminal -> New Terminal`.
